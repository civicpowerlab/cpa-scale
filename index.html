How to export your Outlook (MS Office) calendar so I can work around it:
Mac — Outlook desktop (New or Classic)
1. Open Outlook → switch to Calendar view.
2. File → Export (Classic) or Tools → Export (New Outlook).
3. Choose Calendar / iCalendar (.ics) → date range: Apr 23 → Jun 5, 2026 → detail: Full details.
4. Save to Desktop as liz-calendar.ics, drop the path in chat with me.
Outlook on the web (office.com / outlook.office.com)
1. Calendar → Settings (gear) → Calendar → Shared calendars.
2. Under Publish a calendar, select your main calendar, choose Can view all details, click Publish.
3. Copy the ICS link (ends in .ics). Paste it in chat — I can fetch it directly.
Alt: Settings → General → Privacy and data → Export mailbox works too but is slow.
Windows — Outlook desktop
1. File → Save Calendar → More Options.
2. Date range: Apr 23 → Jun 5, 2026. Detail: Full details.
3. Save as .ics to Desktop. Share the path.
Tip: .ics is far more useful than CSV — it keeps times, durations, and recurrence. If a CSV is all you can get, export from Outlook Web's Import/Export and I'll still work with it.
