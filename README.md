# Collective Political Agency scale (CPA)

Draft instrument, candidate pool v0.2. Two views in one page:

- **Instrument** — the public-facing form: 22 candidate items, fixed interleaved order, no construct labels. PSS-format (0–4 felt-state frequency, 3-month window).
- **Expert review (CVI)** — construct definitions, per-item relevance and clarity ratings (1–4), an independent construct-sorting task, and JSON export for computing I-CVI and sorting agreement.

Five constructs: moral-affective orientation, cognitive-strategic competence, relational embeddedness, collective capacity, institutional responsiveness. Pool trims to ~15 items (3 per construct) after piloting.

Demo only: no data is saved.
